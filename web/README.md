# Music Service Web Application

Веб-приложение для музыкального сервиса, созданное на HTML, CSS и JavaScript.

## Структура проекта

```
web/
├── index.html          # Главная страница с каталогом музыки
├── playlists.html      # Страница управления плейлистами
├── admin.html          # Панель администратора
├── styles.css          # Общие стили приложения
├── script.js           # Основная логика приложения
└── README.md           # Документация
```

## Функциональность

### Главная страница (index.html)
- **Аутентификация**: Форма входа и регистрации
- **Каталог музыки**: Просмотр всех песен с возможностью поиска
- **Детали песни**: Модальное окно с подробной информацией
- **Добавление в плейлист**: Возможность добавить песню в любой плейлист

### Страница плейлистов (playlists.html)
- **Просмотр плейлистов**: Все плейлисты пользователей
- **Создание плейлистов**: Создание новых плейлистов
- **Управление плейлистами**: Добавление/удаление музыки
- **Фильтрация**: Поиск и фильтрация плейлистов

### Панель администратора (admin.html)
- **Управление музыкой**: Добавление и удаление песен
- **Управление пользователями**: Просмотр и удаление пользователей
- **Права доступа**: Доступ только для пользователей с ролью ADMIN

## API Endpoints

Приложение использует следующие эндпоинты согласно openapi-v3.json:

### Аутентификация
- `GET /api/user` - Получение всех пользователей
- `POST /api/user` - Регистрация нового пользователя

### Музыка
- `GET /api/music` - Список всех песен
- `GET /api/music/{id}` - Информация о песне
- `POST /api/admin/music` - Добавление песни (ADMIN)
- `DELETE /api/admin/music/{id}` - Удаление песни (ADMIN)

### Плейлисты
- `GET /api/playlist` - Список всех плейлистов
- `POST /api/playlist` - Создание плейлиста
- `GET /api/playlist/{id}` - Информация о плейлисте
- `POST /api/playlist/music` - Добавление музыки в плейлист

### Администрирование
- `GET /api/admin/users` - Список всех пользователей (ADMIN)
- `GET /api/admin/users/{id}` - Информация о пользователе (ADMIN)
- `DELETE /api/admin/users/{id}` - Удаление пользователя (ADMIN)

## Технические особенности

### Аутентификация
- Использует HTTP Basic Authentication
- Токен сохраняется в localStorage
- Автоматическая проверка авторизации при загрузке страниц

### Интерфейс
- Адаптивный дизайн для мобильных устройств
- Модальные окна для детальной информации
- Уведомления о результатах операций
- Анимации и переходы

### Обработка ошибок
- Централизованная обработка ошибок API
- Пользовательские уведомления
- Graceful fallback для недоступных данных

## Запуск приложения

1. Убедитесь, что backend сервер запущен на `http://localhost:8080`
2. Откройте `index.html` в веб-браузере
3. Зарегистрируйтесь или войдите в систему
4. Используйте навигацию для перехода между страницами

## Роли пользователей

### USER
- Просмотр каталога музыки
- Создание и управление плейлистами
- Добавление музыки в плейлисты

### ADMIN
- Все права USER
- Добавление и удаление музыки
- Управление пользователями
- Доступ к админ панели

## Разработка

Для разработки рекомендуется:
1. Использовать локальный веб-сервер (например, Live Server в VS Code)
2. Настроить CORS на backend для разработки
3. Использовать инструменты разработчика браузера для отладки

## Безопасность

- Все API запросы используют HTTPS в продакшене
- Токены аутентификации хранятся в localStorage
- Валидация данных на клиенте и сервере
- Проверка прав доступа для админ функций
